# Esercizio
Descrivi le specifiche tecniche di un elettrodomestico

# Descrizione
- dimensioni
- capacità
- alimentazione
- modalità di cottura
- efficienza energetica 

## Codifica
``` js
const oven = {
    dimensioni: {
        larghezza: 60,
        altezza: 60,
    },
    capacita: 75,
    alimentazione: "elettrico",
    modalitaCottura: ["statico", "ventilato", "vapore"],

};

console.log(oven);
```
